# studiopass-landingpage

Official high-performance marketing landing page and web portal for **StudioPass** — the unified live audience engagement infrastructure for Radio, Television, and Digital Media Channels across Africa.

## Features Included
- **Hero & Live Interactive Show Simulator**: Real-time presenter chat, animated ticker preview, interactive telephone caller queue preview.
- **Audience & Broadcaster Solutions**: High-conversion feature breakdown for radio stations, TV networks, podcast creators, and event producers.
- **Direct App Download & QR Code**: Seamless access to Android APK and mobile experience.
- **Station Onboarding Portal**: Self-serve broadcaster sign-up and lead qualification form.
- **Contact & Support Portal**: Integrated inquiry submission and WhatsApp direct line.
- **Legal Compliance Suite**: Privacy Policy, Terms of Service, Refund & Credit Policy, and Google Play / Apple App Store compliant Account Deletion request flow.

## Getting Started

Run the development server:

```bash
npm run dev
# or
pnpm dev
```

Open [http://localhost:3000/landing-page](http://localhost:3000/landing-page) in your browser.

## Production Build & Standalone Container

```bash
# Build standalone production bundle
npm run build

# Or build Docker image
docker build -t studiopass-landing .
```
